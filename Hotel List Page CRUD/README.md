# 🏨 Hotel CRUD Application

A responsive **Hotel Management Web Application** built using **ReactJS and Redux**.
The application allows users to browse, search, filter, add, edit, and delete hotel details through a simple and user-friendly interface.

## 🚀 Features

* 🔍 **Search Hotels** – Search for hotels using the search bar.
* 💰 **Price Filter** – Filter hotels based on minimum and maximum price.
* 🏨 **Hotel Listing** – View available hotels with their details and images.
* ➕ **Add Hotel** – Add a new hotel by entering the required details.
* ✏️ **Edit Hotel** – Update the details of an existing hotel.
* 🗑️ **Delete Hotel** – Remove a hotel from the listing.
* 🖼️ **Image Upload & Preview** – Upload and preview a hotel image while adding or editing a hotel.
* 📍 **Location Details** – Store longitude and latitude for each hotel.
* 📄 **Pagination** – Navigate through multiple pages of hotel listings.
* 📱 **Responsive UI** – Designed to work across different screen sizes.

## 🔄 CRUD Operations

This project implements complete CRUD functionality:

| Operation  | Function                    |
| ---------- | --------------------------- |
| **Create** | Add a new hotel             |
| **Read**   | View hotel listings         |
| **Update** | Edit existing hotel details |
| **Delete** | Delete a hotel              |

## 🔎 Search & Filter

Users can search for hotels using the search bar and filter the available hotels according to a selected **minimum and maximum price range**.

## ➕ Adding a Hotel

To add a new hotel:

1. Click on **Add Hotels**.
2. Enter the hotel name.
3. Enter the hotel description.
4. Enter the price.
5. Enter the longitude.
6. Enter the latitude.
7. Upload a hotel image.
8. Preview the image.
9. Click **Publish Hotel**.

The newly created hotel will then appear in the hotel listing.

## ✏️ Editing a Hotel

Each hotel has an **Edit** option.

Clicking **Edit** allows the user to modify the existing hotel information and save the updated details.

## 🗑️ Deleting a Hotel

Each hotel also has a **Delete** option.

The Delete functionality allows users to remove unwanted hotels from the listing.

## ▶️ How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/SwathiSrini14/Hotel-List-Page-CRUD-Form-with-Responsive-UI-/tree/main
```

### 2. Navigate to the project folder

```bash
cd hotel-crud-app
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open the application

Open the local URL displayed in the terminal, usually:

```text
http://localhost:3000/
```
